## 📖 UNIT 1: INTRODUCTION TO COMPUTERS
### Topic 1.1: What is a Computer & The Fundamental IPO Cycle

#### A. Conceptual Understanding (From Scratch)
1. **The Core Reality:** A computer is an electronic machine. It does not think on its own; it executes instructions with astonishing speed and unflinching accuracy.
2. **The IPO+S Principle:**
   - **Input:** Raw facts and numbers (Data) entered via devices like keyboards.
   - **Process:** Mathematical and logical actions performed by the CPU.
   - **Output:** Meaningful, contextual results (Information) presented via monitor or printer.
   - **Storage:** Preservation of data for future access (RAM for now, SSD/HDD for later).
3. **Data vs. Information:**
   - *Data:* Unprocessed, lacks inherent meaning (e.g., `85, 42`).
   - *Information:* Processed, contextualized, and actionable (e.g., `"Roll No 42 scored 85 marks in BCA"`).

#### B. The Classical Digital Computer Block Diagram
```
                     +---------------------------+
                     | CENTRAL PROCESSING UNIT   |
                     |  +---------------------+  |
                     |  |  Control Unit (CU)  |  |
+------------+       |  +---------------------+  |       +------------+
|   INPUT    |======>|  |  Arithmetic Logic   |  |======>|   OUTPUT   |
|   UNIT     | Data  |  |  Unit (ALU)         |  | Info  |    UNIT    |
+------------+       |  +---------------------+  |       +------------+
                     |  |  Registers / Cache  |  |
                     |  +---------------------+  |
                     +-------------^-------------+
                                   |
                                   v Bi-directional
                     +---------------------------+
                     |       MEMORY UNIT         |
                     | - Primary (RAM / ROM)     |
                     | - Secondary (SSD / HDD)   |
                     +---------------------------+
```

#### C. University High-Scoring Exam Notes
- **Standard Definition (2 Marks):** "A computer is an automatic, programmable electronic data processing system that accepts raw data, executes logical and arithmetic instructions under program control, produces refined information, and stores results for future retrieval."
- **Functions of Control Unit (CU):** Known as the central nervous system. It does not perform computations; it fetches, decodes, and orchestrates signals to coordinate memory, ALU, and I/O units.
- **Functions of Arithmetic Logic Unit (ALU):** Carries out arithmetic operations ($+, -, \times, \div$) and relational comparisons ($<, \le, >, \ge, =, \neq$).

#### D. Memory Retention Mnemonics
- **IPO+S:** *"I Prefer Orange Soda"* (Input, Process, Output, Storage).
- **CPU Anatomy:** *"Always Control Results"* (ALU, CU, Registers).
