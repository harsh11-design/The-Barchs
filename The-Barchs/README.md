# Barchs – The Business Architects

Professional consulting website featuring responsive luxury header, interactive navigation drawer, services & industry architecture, SEO pillar guides, and business diagnostic calculators.

## How to Host on GitHub Pages

1. Create a new repository on GitHub and upload all files in this folder.
2. Go to **Settings > Pages**.
3. Under **Build and deployment > Source**, select **GitHub Actions** (the included .github/workflows/deploy.yml workflow will automatically build and publish the live site!).
4. Your site will be published at https://<your-username>.github.io/<repo-name>/.
